# Scenario:
```
You have a string and a number k . Rotate the string to the right by k positions.

Explanation:

. Take last k characters and move them to the front.

Input Format:

. First line: string s
. Second line: integer k

Output Format:

. The rotated string.

Constraints:

· 1≤len(s) ≤ 1000
· 0≤k≤ 1000
Sample Input:

abcdef
2

Sample Output:

efabcd

Explanation of Output:

Move last 2 characters "ef" to the front :- > "efabcd".
```
