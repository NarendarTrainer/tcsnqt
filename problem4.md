# Scenario:
```
In many computer graphics problems, you need to generate patterns.
Write a program that prints a pyramid of * for a given number of rows.

Explanation:

. Print increasing number of stars *

Input Format:

· A single integer n (number of rows).

Output Format:

. Pyramid of stars, each line centered.

Constraints:

. 1≤n≤20



Sample Input:

4

Sample Output:
   *
  ***
 *****
*******

Explanation of Output:

· 1st row: 1 star
. 2nd row: 3 stars
. 3rd row: 5 stars
. 4th row: 7 stars
